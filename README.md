## 🛰️ What Is Orbital-Desk?

**Orbital-Desk** is an open-source educational sky hub — a modular learning environment that treats knowledge the way an observatory treats the night sky: as something vast, layered, and worth mapping patiently. It began its life as a study companion for students who wanted a single, calm dashboard to organize study sessions, reference materials, and collaborative note-taking — and it has since grown into a full ecosystem for self-directed learners, tutors, and small classroom groups.

If you have ever wished your study workflow felt less like juggling and more like navigating, Orbital-Desk is the cockpit you've been looking for. It doesn't shout at you with notifications. It doesn't sell your attention to advertisers. It simply gives you a beautifully arranged instrument panel, and lets you steer.

## ✨ Why Learners Orbit Around This Project

Most study tools are built for compliance — check the box, finish the quiz, move on. Orbital-Desk is built for **curiosity-driven retention**. Every design decision in this repository flows from a single question: *does this help a learner remember something six months from now?*

That question shaped the roadmap into seven distinct orbital rings, each described below with the honesty and depth of a mission briefing.

## 🚀 Core Feature Constellation

### 🌠 Ring One — Adaptive Study Canvas
An infinite, tagging-aware workspace where notes, flashcards, diagrams, and references live side by side. The canvas remembers relationships between topics, so when you open "Thermodynamics" you also see the "Statistical Mechanics" bridge you sketched three weeks ago. Everything is local-first, everything is searchable, and nothing disappears into a folder you'll never open again.

### 🌍 Ring Two — Multilingual Learning Support
Twenty-eight languages ship out of the box, with community-contributed translations reviewed by native speakers. Right-to-left scripts render cleanly, CJK characters display without layout drift, and the interface respects regional conventions for dates, numbers, and academic calendars. Language should never be a wall between a learner and their subject.

### 📱 Ring Three — Responsive Interface Across Devices
Start a session on a desktop in the library, continue it on a tablet during a commute, glance at progress on a phone before bed. The layout adapts fluidly — not by shrinking, but by re-composing itself intelligently. Buttons that matter stay large; decorative elements step aside. The result feels less like a mobile website and more like a native application in every context.

### 🧭 Ring Four — Focus Beacon Sessions
A pomodoro-inspired pacing system that learns your natural attention rhythm. Instead of rigid 25-minute blocks, Focus Beacon observes when your note-taking slows or speeds up, and suggests session lengths tuned to your actual cognitive cadence. Gentle ambient audio, optional dimming, and a distraction ledger round out the experience.

### 🔭 Ring Five — Observatory Analytics
Charts and heatmaps that visualize your learning streaks, topic density, and retention curves. No vanity metrics — every graph answers a practical question like "Which subject am I neglecting?" or "What time of day do I absorb the most?" Data stays on your machine unless you explicitly choose to sync.

### 🤝 Ring Six — Collaborative Study Orbits
Create shared study rooms where peers can co-edit notes in real time, annotate each other's flashcards, or run a quiet group session with a shared timer. Permissions are granular: viewers, contributors, and moderators each see a purpose-built interface.

### 🛡️ Ring Seven — 24/7 Support Layer
A help desk that never sleeps — staffed by community maintainers rotating across time zones, supplemented by an in-app assistant that answers common questions instantly. Real humans remain reachable for anything the assistant can't untangle. If you're stuck at 3 a.m. before an exam, someone is there.

## 🎨 Design Language

Orbital-Desk draws its visual vocabulary from astronomy and cartography. Deep indigo backgrounds mimic the night sky; accent colors echo nebula photography; typography is deliberately quiet so that *your content* is the brightest thing on screen. The iconography uses thin line work reminiscent of star charts.

Dark mode and light mode are both first-class citizens. A third "Twilight" theme splits the difference for late-afternoon sessions. Every theme is tested against WCAG 2.2 AA contrast guidelines.

## 🧩 Modular Architecture Overview

The project is deliberately modular: no single file grows beyond a few hundred lines, and each module owns exactly one concern. This makes it approachable for newcomers and maintainable for the long haul.

| Module | Responsibility | Maturity |
|---|---|---|
| Canvas Core | Note graph, tagging, rendering | Stable |
| Beacon Scheduler | Session pacing & analytics | Stable |
| Polyglot Layer | i18n and locale data | Stable |
| Sync Bridge | Optional local-network sync | Beta |
| Orbit Rooms | Real-time collaboration | Beta |
| Analytics Engine | Visualization pipeline | Stable |
| Assistant Runtime | In-app Q&A helper | Alpha |

## 🌐 Multilingual Support In Practice

Localization is not an afterthought bolted on at the end. Every user-facing string passes through the Polyglot Layer, which enforces pluralization rules, gendered forms where languages require them, and context-aware abbreviation. Adding a new language involves editing a single JSON file and submitting a pull request — no code changes, no build gymnastics.

Currently shipped locales include: Arabic, Bengali, Chinese (Simplified & Traditional), Czech, Danish, Dutch, English, Finnish, French, German, Greek, Hebrew, Hindi, Hungarian, Indonesian, Italian, Japanese, Korean, Norwegian, Polish, Portuguese (Brazil & Portugal), Romanian, Russian, Spanish, Swedish, Thai, Turkish, Ukrainian, and Vietnamese.

## 🤖 Support Model Explained

The 24/7 support layer works in three tiers:

- **Tier One — Instant Assistant:** An in-app helper trained on our documentation and issue history. It answers routine questions in under two seconds and escalates gracefully when uncertain.
- **Tier Two — Community Desk:** Volunteer maintainers monitor chat channels around the clock, rotating by region. Median first-response time is under twelve minutes.
- **Tier Three — Maintainer Escalation:** For bugs, security reports, or architectural questions, a core maintainer responds within one business day.

We do not use automated chatbots to *pretend* to be human. When you talk to a person, it will be obvious.

## 🔐 Privacy Stance

Orbital-Desk stores your data locally by default. There is no telemetry, no analytics beacon, no "anonymous usage statistics" quietly running in the background. If you enable the optional Sync Bridge, data is transmitted only across your own local network — never through our servers, because we don't operate any.
